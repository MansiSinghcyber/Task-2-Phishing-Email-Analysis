# Task 2 - Phishing Email Analysis

## Objective

Analyze a phishing email and identify phishing indicators.

## Dataset

Hugging Face Dataset

Teddyha/phishing_benign_email_dataset

## Tools Used

- Kali Linux
- Python
- Hugging Face Datasets
- Nano Editor

## Steps Performed

- Downloaded phishing dataset
- Loaded dataset using Python
- Extracted phishing sample
- Saved sample as text
- Analyzed sender
- Examined suspicious URL
- Identified phishing indicators
- Documented findings

## Phishing Indicators Found

- Email spoofing
- Urgency
- Suspicious URL
- Credential harvesting
- Brand impersonation
- Social engineering

## Conclusion

The email is a phishing email because it attempts to trick users into revealing sensitive information.
